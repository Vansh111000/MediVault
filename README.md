# MediVault

**MediVault** is an AI-powered personal medical history and consultation assistant that provides a centralized platform for managing and accessing patient medical records across registered hospitals and clinics. It enables secure, consent-based sharing of medical history, digital consultations and prescriptions, visit-based access control, and AI-assisted extraction, organization, summarization, and explanation of medical records.

An FSDL PROJECT

To run the frontend, go to frontend directory then npm run dev

to run the backend, go to backend directory and run node server.js or npm run dev (if you have nodemon installed)
